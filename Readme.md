# Order Tracking Screen

A single-file, dependency-free mobile order tracking experience for an e-commerce app. Built with plain HTML/CSS/JS so it runs anywhere with zero build step.

**Live demo:** https://claude.ai/artifact/MwuDY9j8QHgmDiQxYa3bkU

## What's inside

use TailwindCss, Html, Javascript
Google Fonts Rubik + FontAwesome are used.


`active-order-delivery.html` — the has order accepted and countdown not started. 


A brief loading skeleton also plays on first load and whenever you switch states, standing in for a real network fetch.

Other interactions: **Contact support** (call / chat ), **View order details** at evry page for easy view.

## Run it locally

No build tools, no dependencies. Either:

```bash
# Option A — just open it
open file and open with live server   # or double-click the file

npm i .
npm run dev
```
